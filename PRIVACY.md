# NiiMotion privacy

NiiMotion processes motion sensor data locally on the Windows PC. Raw Joy-Con, PS Move, phone, HMD, and Balance Board recordings are not uploaded by the application. Personal calibration and learned gait profiles stay under the local NiiMotion data folders unless the user explicitly exports a backup or diagnostic package.

Diagnostic exports exclude raw motion recordings and learned models. Private IP addresses, Bluetooth identities, and the Windows user-folder path are redacted. Online access is used only for explicitly requested game metadata and configured update checks.

Users can create or restore local snapshots and reset learned motion data from the Backup and Restore screen.
