# NiiMotion closed beta acceptance plan

Use this only after the owner hardware matrix and clean Windows installation pass.

## Minimum coverage

- 5–10 Windows PCs with at least three different Bluetooth adapters.
- Quest 3 is the required reference headset; other Quest models are compatibility observations, not implied support.
- At least three SteamVR/OpenVR games and two OpenXR games.
- Joy-Con and PS Move single-device profiles plus at least two mixed profiles.
- One uninterrupted 60-minute session and one sleep/disconnect/reconnect session per tester.

## Evidence labels

- `automated-tested`: deterministic software verification only.
- `replay-tested`: recorded sensor data passed through the runtime.
- `owner-hardware-verified`: project owner completed the scenario.
- `beta-hardware-verified`: an external beta machine completed the scenario.

## Privacy

Collect the privacy-safe diagnostic package and session-health summary only after explicit tester action. Raw recordings remain local unless the tester separately chooses and approves a specific recording.
