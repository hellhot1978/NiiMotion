# Licensing decision before public release

The repository currently has no public-source license grant, so normal copyright protection applies. This avoids accidentally granting rights before the owner chooses the GitHub and Steam distribution model.

Before making the repository public, choose one of these deliberately:

- **GPL-3.0:** improvements distributed to users remain open under the same license.
- **Apache-2.0:** permissive reuse with an explicit patent grant.
- **MIT:** short permissive terms, without Apache's detailed patent language.
- **Source available / commercial:** public inspection with restricted redistribution, requiring custom legal terms.

`THIRD_PARTY_NOTICES.md` must remain with every distribution. Valve OpenVR SDK material is BSD-3-Clause; each additional asset and dependency must retain its own notice. A final root `LICENSE` file should be created only after the owner selects the intended model.
