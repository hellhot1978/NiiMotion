# Device setup guide

## Joy-Con

Pair both controllers in Windows Bluetooth settings. Validate the left and right Joy-Con from their app cards, then secure them to the upper legs between hip and knee. Press any button to wake a sleeping Joy-Con; NiiMotion searches for the same stored identity again.

## PS Move CECH-ZCM1

In the setup wizard, connect the left Move by USB first and pair it. NiiMotion reads factory calibration and assigns a red sphere. Disconnect USB and press the Move button to switch to Bluetooth. Repeat for the right Move; it receives a blue sphere. Mount both controllers below the knee/on the calf, facing the same direction. Battery status and re-pairing are available on the device screen.

## Android phone / owoTrack

Secure the phone horizontally on the chest, screen facing the chest and top edge pointing left. Open owoTrack on the phone. Select the phone card in NiiMotion to enter pairing mode and wait for live packets. Phone-only locomotion is experimental; with leg sensors the phone is supporting evidence.

## Wii Balance Board

With the board empty, press SYNC and complete Windows Bluetooth pairing. Run center-of-pressure calibration in this order: empty board, centered stance, guided weight transfer. Do not physically rotate the board; game turning follows the selected profile policy.

## Quest 3, Virtual Desktop and hands

The Quest card reports connected only from a fresh trustworthy signal; process presence alone is insufficient. The Virtual Desktop card reflects the real streamer/session state. Hand tracking is not required by the walking engine and affects only hand/controller use in VR.
