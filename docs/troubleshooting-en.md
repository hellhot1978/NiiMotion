# Troubleshooting

- **Left/right Move went to sleep:** Press the Move button. NiiMotion searches for its stored Bluetooth identity. If it does not return, use **Pair again** in device calibration.
- **Phone data is stale:** Confirm that owoTrack is open and both devices are on the same local network, then select the phone card to restart pairing.
- **Virtual Desktop looks connected but SteamVR reports error 1114:** Close SteamVR, wait for the Virtual Desktop VR session inside the Quest to become ready, then start it from NiiMotion.
- **Joy-Con disconnected after being idle:** Press any button to wake it. Locomotion remains safely at zero until the connection returns.
- **Board light keeps blinking:** Windows pairing alone does not prove live data. Wake the board and wait for automatic discovery.
- **The game does not move:** Confirm that Normal VR is not selected, required device cards are ready, base calibration is complete and the game adapter is supported.
- **Combined calibration required:** Complete the three combined phases for the selected multi-device profile. Ready individual devices do not replace the fusion model.
- **I recorded a combined phase incorrectly:** Use the ↻ button next to that phase. The phase and later phases reopen, and the current fusion model is backed up.
- **The new fusion model feels worse:** Use **Restore Previous Combined Model** in the combined calibration window. Individual device models are not changed.
- **Support package:** Open Test & Calibration → System Diagnostics. The package excludes raw sensor recordings and masks private information.
- **Restore an earlier model:** Open Test & Calibration → Recovery Center. The current state is backed up before restoration.
