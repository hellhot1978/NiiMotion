# Hızlandırılmış dayanıklılık doğrulaması

2026-08-22 tarihinde dört saatlik sanal süre, 50 Hz hızlandırılmış replay ile 720.000 sensör çevrimi olarak çalıştırıldı. Senaryo yürüyüş/duruş döngülerini, sensör sessizliğini, acil sıfırlamayı ve profil geçişi güvenlik sözleşmesini kapsar.

Kabul ölçütleri: çıktı test sonunda tam sıfır, adım motoru etkin, ayrılan yönetilen bellek 256 MB altında ve bütün otomatik regresyonlar başarılı. Gerçek Bluetooth radyo dayanıklılığı bu testin kapsamında değildir; daha sonraki donanım oturumu bunu ayrıca doğrulayacaktır.
