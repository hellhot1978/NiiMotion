# First use

1. Open **My Devices** and select only the hardware you own.
2. Complete the three guided five-minute phases for each motion sensor. A mistaken phase can be reset independently.
3. Select a ready profile on **Overview**. Profiles using uncalibrated devices remain unavailable.
4. Select a VR game. NiiMotion validates sensors, Quest/Virtual Desktop, SteamVR, and the game in that order.
5. Use **Normal VR** whenever native controller locomotion is desired. NiiMotion begins with motion output disabled.

The in-app Getting Started screen mirrors these steps and reflects completed calibration stages.
