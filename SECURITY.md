# Security Policy

NiiMotion is currently pre-release software. Security reports should use GitHub's private **Report a vulnerability** feature when the repository is published. Do not include raw sensor recordings, IP addresses, Bluetooth identities, user paths, or diagnostic archives in a public issue.

Include the affected version, Windows version, runtime (SteamVR/OpenXR), reproduction steps, and whether the issue can create unintended movement or bypass a launch gate. Use the application's privacy-safe diagnostic package when possible.

Safety issues involving unintended locomotion, failure to return to neutral output, unsafe driver installation or rollback, update integrity, or disclosure of local movement data are treated as high priority.
